# .NET Interview Flashcards

🧠 C#
Q: Why are strings immutable?
A: Thread safety, memory efficiency, interning.

Q: When use record instead of class?
A: For immutable, value‑based models.

Q: Why is Span<T> faster?
A: Avoids allocations, slices memory directly.

Q: What problem does ValueTask solve?
A: Reduces allocations when async completes synchronously.

---

🌐 ASP.NET Core
Q: Why is DbContext scoped?
A: One unit of work per request.

Q: Why does middleware order matter?
A: Each wraps the next; wrong order breaks pipeline.

Q: When use custom middleware vs filter?
A: Middleware for cross‑cutting, filters for MVC.

Q: Why keep controllers thin?
A: Separation of concerns, no business logic.

---

🗄️ EF Core
Q: What happens on SaveChanges()?
A: Translates tracked changes into SQL + transaction.

Q: Why AsNoTracking()?
A: Faster reads, no change tracking.

Q: Cause of N+1 problem?
A: Lazy loading multiple queries.

Q: Projections vs Include()?
A: Projections fetch only needed fields.

---

💾 SQL
Q: Why index slows writes?
A: Extra work updating index.

Q: Identify slow query bottleneck?
A: Execution plan, missing indexes, scans.

Q: What is covering index?
A: Index with all needed columns.

Q: Why pagination matters?
A: Avoids huge result sets, faster response.

---

⚡ Performance
Q: Why API slow in prod?
A: Real load, DB contention, latency.

Q: Identify thread pool starvation?
A: Queued tasks, long waits, metrics.

Q: Redis vs in‑memory cache?
A: Redis for distributed, in‑memory per instance.

Q: Metrics before optimizing?
A: CPU, memory, DB queries, latency.

---

🔒 Security
Q: Invalidate JWT early?
A: Blacklist or rotate signing key.

Q: Why not store sensitive info in JWT?
A: Tokens are client‑visible.

Q: Protect public API?
A: Rate limiting, API keys, throttling.

Q: Why refresh tokens?
A: Secure long‑lived sessions.
