# my-ai-skills

Personal Claude Skills for .NET/React engineering workflow.

## Skills
- `dotnet-stack/` — aggregate router; consult this first for multi-concern tasks
- `dotnet-production-code/` — ASP.NET Core production code conventions
- `dotnet-testing/` — xUnit unit + integration test conventions
- `cicd-pipeline/` — GitHub Actions, Artifactory, Argo CD, AKS conventions
- `react-frontend/` — React/TypeScript conventions
- `git-workflow/` — commit message conventions

Each skill is a folder containing a `SKILL.md` (required) and optionally
`scripts/`, `references/`, `assets/` subfolders for bundled resources.
